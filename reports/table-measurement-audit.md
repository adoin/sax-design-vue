# Table 测量缓存验收（2026-09-05）

## 范围与复现

组件基线为 `6bfcd93`。本次补齐缓存失效规则的中英文说明和可重复浏览器验证，没有修改组件实现。

启动文档开发服务后运行 `pnpm audit:table-measurements`。脚本通过现有 `play/table-audit` 隔离页面挂载真实 STable，记录到 `table-measurements-browser.json`。普通数组为 1000 行 × 30 列；生成源为 100 万行 × 10 万列。两者开启双轴虚拟化、动态行高及左右固定列。

每种数据源连续执行 17 个阶段，覆盖内容增长、横向换列、加宽/恢复列宽、显隐、重排/恢复顺序、原地内容更新、显式重测、数据引用更新及容器宽度变化。断言检查末行仍挂载、行列窗口和测量元素/ref 数量有界，以及每个数据格与所在行的顶部和高度一致。

## 缓存契约

| 变化 | 数据行的处理 | 验证依据 |
| --- | --- | --- |
| 横向窗口切换 | 同一稳定行键保留最大已测高度，长内容列卸载后不回缩 | 两种数据源的真实横向窗口切换；断言长列确实离开窗口 |
| 可见内容增高 | ResizeObserver 更新自然高度 | 引用替换与原地更新均实测 |
| 列宽、容器宽度、列显隐或顺序变化 | 清空旧布局测量并重新测量当前窗口，允许回缩 | 两种数据源的宽度、显隐、重排和容器变化实测 |
| `data` 数组或 `virtualSource.row` 回调替换 | 清空旧行高测量，允许内容缩短 | 普通数据数组替换、生成源回调替换实测 |
| 原地缩短字段、插槽或回调外部数据 | 保留最大高度；更新内容后调用 `measure()` 可释放旧高度 | 两种数据源使用同一行对象/回调，通过响应式字段读取更改可见内容，随后显式重测 |
| 表尾窗口切换、数据变化与重测 | 表尾拥有独立高度缓存；换列保留，数据变化或 `measure()` 重置 | `table-footer.test.ts` 的保留/重置/卸载检查，加上父表列布局监听的源代码核对 |
| 合并格与详情内容 | 合并格保留相同内容在各片段的最大要求；真实内容变化允许回缩。详情缩短、关闭或禁用触发重测 | `table-merge-heights.test.ts`、`table-merge-measurement.test.ts`、`table-details.test.ts` |

`table.vue` 的布局监听不依赖横向可见列窗口，依赖列宽修订、列状态、受控列宽、容器宽度以及列尺寸配置；`measure()` 同时清除合并高度、重置虚拟行高并测量表尾/横向视口。普通列表与生成源分别由 VirtualList 和 sparse virtualizer 维护稳定行键测量。高度历史随访问过的键增长，只有测量 DOM、回调和待处理测量被窗口约束，不能将全部缓存表述为 O(可视行数)。

## 浏览器结果

| 过程 | 普通数组末行高度 | 生成源末行高度 |
| --- | ---: | ---: |
| 长内容 | 539px | 1058px |
| 长列离开横向窗口 | 539px | 1058px |
| 列宽 140 → 560px | 129px | 193px |
| 隐藏长列，或将长列重排出窗口 | 42px | 64px |
| 恢复长列 | 539px | 1058px |
| 原地缩短后、尚未显式重测 | 539px | 1058px |
| `measure()` 后 | 42px | 64px |
| 替换数据引用/取行回调，内容缩短 | 42px | 64px |

普通数组最多挂载 15 行、9 个表头、15 个测量 ref；生成源最多挂载 12 行、9 个表头、12 个测量 ref。所有采样的数据格顶部及高度偏差都低于 1px，卸载后隔离容器没有残留 DOM。

普通数据列重排后，位置索引会改变；脚本用该隔离数据的字段标识核对长列是否仍在窗口，并通过稳定列键定位。生成源通过原始数值索引定位。首次重排断言将位置索引误当稳定标识，修正的是验收脚本，未据此修改组件。
