# 将 Image Generation 点阵替换为 Logo 或实体线束

用户澄清：“我意思是在原本的点阵动画中加上我们的这两个设计元素重新设计”。随后指出：“这三坨线没必要吧，另外就是还有很多点阵没有颜色飘过去过”。

不得以大号 S 标志替换点阵，也不得叠加三段独立实体线。保留点阵为主视觉，以 Logo 的靛蓝、紫色、青绿和 Loading 的流动节奏设计点的颜色、亮度与尺寸。色彩流动须覆盖整个画布，包含边缘，不能只在中间带状区域循环。
