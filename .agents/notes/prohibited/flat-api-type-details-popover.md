# 禁止使用整段类型表达式的扁平弹层

## 尝试过的方案

把完整类型表达式渲染成一个交互按钮，为整段表达式打开一个弹层，在同一个面板中列出所有可达声明，以悬停作为主要触发方式，并允许点击固定该面板。

## 证据

`ApiTypeDetails.vue` 当前的扁平实现采用了这个方案。用户在检查 `Boolean | TableClipboardConfig` 等复合类型后明确否定了它，并要求：只有被引用的自定义类型可以点击；第一层显示该类型自己的声明；声明内部继续引用的类型可以再打开更高一层，而且不能关闭已有层。

## 禁止原因

- 无法表达哪个 token 对应哪个声明。
- 无法表达递归类型引用链。
- 单一聚合面板妨碍逐层对照和复制。
- 悬停主导的交互不利于移动到面板、选择和复制内容。
- 各弹层独立处理外部点击时，操作子层会错误关闭祖先层。

## 必须采用的方向

对每个类型表达式和声明进行 token 化与语法高亮，只把可解析的引用类型标识符渲染成点击目标。将所有面板作为一条可递归扩展的栈统一管理：每次点击在现有栈上方打开一个声明层，祖先层保持打开；只有点击所有触发器和弹层之外时，共享的外部边界才关闭完整栈。定位继续复用 `SPopper`，通过扩展或组合共享浮层行为解决跨 Teleport 边界，不能另建第二套绝对定位系统。
