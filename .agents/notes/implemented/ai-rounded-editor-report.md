# AI 组件圆角与工作汇报编辑示例

## 用户要求

> AI相关的这些组件暂时都不需要方角，先从代码层级删除；AI Editor那个SVG文件太丑了。。。而且文档放第一个的不应该是默认吗？另外行内格式的询问AI为什么是灰色的不能点，然后文档的几个例子也莫名其妙的，像个好点的类似在写工作汇报的例子吧。

## 当前契约

- 所有 AI 分类组件移除公开 shape、useShape 解析、方角样式与方角示例。内部共享控件明确圆角，不继承全局 square。
- 保留全局圆角尺寸和主题 token；公共 API 不承诺方角兼容。
- AI Editor 默认图标采用简洁线形 SVG，保留 ai-icon URL 与插槽定制。
- 双语文档顺序一致：默认、行内格式、异步请求、流式回答、自定义插槽、AI 图标。
- 示例使用客户门户周度汇报：成果、权限迁移风险、下周计划。行内格式示例配置本地 answer，询问 AI 可操作；无 request/answer 的业务实例依旧不能假装调用服务。
- Code / Playground 从对应完整 SFC 同步。此前 AI shape 示例与共享 shape 的记录由本契约取代，其他组件 shape 契约不变。

## 完成条件

组件回归、文档检查、web/play 类型、主题构建通过；验证两种语言默认顺序、询问 AI 与应用回答，所有 AI 文档无方角入口。

## 验证

- 55 项 AI Editor / Agent 组件回归、21 项文档检查通过。
- web、play、vitest 类型检查和主题构建通过。
- 浏览器逐项确认 AI Editor 12 个双语 Code / Playground 示例，以及其他 13 个组件共 26 个双语示例，无方角标题且均能渲染。
- 行内格式示例实际完成选择成果段、输入润色问题、等待完整回答、替换选区；风险与计划段保留。两种语言都以默认示例开头，图标定制位于最后。
- 默认 SVG 换为主题色线形星芒，图片 SVG 示范使用现有 Sax 标志素材；保留 PNG 与插槽入口。
