# Component global-default audit — 2026-09-14

## Eligibility rule

A prop is global-default eligible only when it represents a stable application or subtree policy and remains meaningful across unrelated instances. Controlled values, data, content, callbacks, field mappings, per-record permissions, and layout dimensions tied to one instance are excluded.

## Public component review

| Component family              | Reviewed components                                                                                                                                                                                                                                                                | Decision                                                                                                                                                                                                              |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Application context           | `SConfigProvider`                                                                                                                                                                                                                                                                  | Owns namespace, theme, locale, time zone, Now behavior, shape, shared size, and component policy objects. The legacy semantic `color` map is retained for compatibility but is not treated as a component prop default.                                                              |
| Shared-size controls          | `SButton`, `SInput`, `SDatePicker`, `STimePicker`, `SRate`, `SSteps`, `STabs`, `STag`                                                                                                                                                                                              | Inherit global `size`; an explicit local size wins.                                                                                                                                                                   |
| Shape-aware controls          | `SButton`, `SCard`, `SCascader`, `SColorPicker`, `SContextMenu`, `SDatePicker`, `SDialog`, `SInput`, `SInputNumber`, `SPagination`, `SSelect`, `SSlider`, `SSwitch`, `STableSelect`, `STag`, `STextarea`, `STimePicker`, `STimeSelect`, `STooltip`, `SUpload`, `SVerificationCode` | Continue to inherit global `shape`; unsupported geometry is normalized by the component.                                                                                                                              |
| Reusable interaction policy   | `SButton`, `SDialog`, `SDrawer`, `SNotification`, `SPagination`, direct `SPopper`                                                                                                                                                                                                  | Added typed component-default objects. Composite popper consumers retain their own defaults.                                                                                                                          |
| Navigation                    | `SAnchor`, `SAffix`, `SBacktop`, `SBreadcrumb`, `SLink`, `SMenu`, `SNavbar`, `SSidebar`, `STabs`                                                                                                                                                                                   | Anchor keeps its existing router/boundary global object. Other navigation inputs describe one route tree, target, viewport, or information structure and remain local.                                                |
| Data grids                    | `STable`, `STableColumn`, `STableColumnConfig`, `STableSelect`                                                                                                                                                                                                                     | Added typed defaults to `STable`. Columns, data-model state, and business callbacks remain local. Table Select keeps its narrower selector defaults rather than inheriting unrelated editing or spreadsheet policies. |
| Forms and selection           | `SForm`, `SFormGroup`, `SFormItem`, `SCheckbox`, `SCheckboxGroup`, `SRadio`, `SRadioGroup`, `SRadioButton`, `SSelect`, `SOption`, `SOptionGroup`, `SCascader`, `SInputNumber`, `SSlider`, `SSwitch`, `STextarea`, `STimeSelect`, `SVerificationCode`                               | Model values, rules, labels, field paths, option data, limits, and validation timing are instance semantics. Shared shape/size/locale already cover the safe common layer.                                            |
| Date and schedule             | `SCalendar`, `SDatePanel`, `SDatePicker`, `STimePicker`, `SCountdown`                                                                                                                                                                                                              | Locale, time zone, and Now behavior are global. Views, event data, adapters, ranges, and scheduling dimensions remain local. Calendar's `medium` scale is intentionally not coerced into shared `default`.            |
| Overlays                      | `SPopper`, `STooltip`, `SPopconfirm`, `SContextMenu`, `SDialog`, `SDrawer`, `SImagePreview`, `SPrompt`, `SOverlay`                                                                                                                                                                 | Direct Popper, Dialog, and Drawer expose safe policy defaults. Higher-level overlays preserve specialized close/focus/position defaults; content and controlled visibility remain local.                              |
| Feedback                      | `SAlert`, `SBadge`, `SLoading`, `SNoticeBar`, `SNotification`, `SProgress`, `SResult`, `SEmpty`                                                                                                                                                                                    | Notification duration/position policy is global. Other props describe the current status, content, progress, or target and remain local; locale remains shared.                                                       |
| Media and files               | `SAvatar`, `SAvatarGroup`, `SIcon`, `SLogoLoading`, `SImage`, `SImages`, `SImagePreview`, `SIconPicker`, `SUpload`, `SWatermark`                                                                                                                                                   | Sources, previews, file validation/request policy, user identity, and watermark content are application data or security boundaries and remain local. Shape applies where supported.                                  |
| Content and containers        | `SCard`, `SCardGroup`, `SCollapse`, `SCollapseItem`, `SList`, `SListHeader`, `SListItem`, `SText`, `STextEllipsis`, `SDivider`                                                                                                                                                     | Variants and truncation/collapse state express local hierarchy and content. Shape is the only safe shared default where supported.                                                                                    |
| Layout                        | `SRow`, `SCol`, `SLayout`, `SLayoutContainer`, `SLayoutHeader`, `SLayoutAside`, `SLayoutBody`, `SLayoutFooter`, `SControlGroup`, `SSpacer`, `SSplitter`, `SSplitterItem`                                                                                                           | Grid spans, gaps, regions, pane sizes, and breakpoints are instance layout, not application policy.                                                                                                                   |
| Motion and viewport utilities | `SCarousel`, `SScrollbar`, `SVirtualList`, `SInfiniteScroll`, `SCollapseTransition`                                                                                                                                                                                                | Timing and dimensions are coupled to content and scroll ownership. Table virtualization owns its own reusable policy; low-level utilities remain explicit to avoid silently changing nested components.               |
| Printing and infrastructure   | `SPrint`, `SPrintPageBreak`, `SFocusTrap`, `STeleport`, `SSlot`, `SVisualHidden`                                                                                                                                                                                                   | Targets, page breaks, focus boundaries, and teleport destinations are instance/infrastructure concerns and remain local.                                                                                              |

## Result

The audit does not equate “has a default” with “belongs in ConfigProvider.” The implemented surface covers defaults that can safely repeat, while the excluded props stay explicit so Provider configuration cannot couple unrelated data models or override specialized component semantics.
