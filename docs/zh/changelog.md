# 更新日志

## 未发布

## 2.8.4

- Table 默认空状态统一使用 Empty 组件，保留自定义文字和插槽。
- 修复横向滚动时空状态与固定列重叠的问题，普通及虚拟表格均保持在可视中间区域。

## 2.8.3

- 修复 Cascader 空选中值的自定义显示文字与浮动标签、占位文字重叠的问题。

## 2.8.2

- 修复 Select 选中空字符串或与 `notValue` 相同的选项时，浮动标签与选项文字重叠的问题。

- 优化文档开发环境首次加载：组件按需加载、合并图标注册、缓存原生 Sass 编译结果，并延后加载 Playground；支持独立缓存目录复现冷启动。

## 2.8.1

- 修复 Form 公共声明中的模型泛型推断，保留字段、验证器、事件类型及动态插槽的控件 ID。


## 2.8.0

- 文件管理器未匹配缩略图时，一至两个字符的后缀显示在默认文件 SVG 内，较长后缀保持普通图标。

- 右键菜单支持二级及多级菜单；文件管理器的排序依据与升降序统一收进“排序”子菜单。

- 完善文件管理器：整行工具栏插槽、空白处右键自定义排序、Home 与文件夹开合图标、后缀缩略图、树内文件和隐藏项操作。

- 复用组件与安装能力的公共类型引用，减少重复声明，保留属性、事件、插槽和实例方法的类型提示。

- 新增 File Manager 文件管理器：目录树、面包屑、虚拟图标／列表、拖放、快捷键与可全局配置的操作习惯。
- 文件夹封面支持插槽，文件预览支持按后缀／MIME 配置渲染器；异步操作钩子可接入持久化与确认流程。

## 2.7.0

发布日期：2026 年 10 月 21 日。配套图标插件为 `sax-design-vue-iconify` 1.1.0。

- 新增 `signSvgs` Vite 插件，将项目 SVG 文件注册为 `lo-home` 等名称，可用于 Icon 和其他组件的图标属性，也支持动态名称。开发时文件变化会自动刷新页面。
- 本地 SVG 仅打包静态引用及 safelist，并复用相同数据。IconPicker 改为通过可配置 API 加载缺少的候选数据，不再内置候选 SVG 集合；内部控件图标仍可离线使用。
- 补充 IconPicker 网络依赖、内网 Docker API 部署与完全离线应用打包说明。

参见[本地 SVG 文件](./icons/#local-svg-files)。

## 2.6.1

发布日期：2026 年 10 月 20 日。

- 图标变形升级至 `svg-morpheus-ts/core` 2.0.0。
- 原生描边新增、消失的轮廓沿自身路径画出/收回；填充图形继续使用几何插值，并保留复合轮廓与孔洞。
- 连续改变目标时保留当前几何与绘制快照，不反复扩增路径；描边切到填充图形时，退出路径保持透明，避免残留圆端点。
- 保留现有 `morph`、全局 `icon.morph`、时长与弹簧配置，继续遵循系统减少动态效果设置。

参见[图标用法](./icons/#morphing)。

## 2.6.0

发布日期：2026 年 10 月 20 日。

- 新增可选图标变形，支持多色、透明度、线性/径向渐变、SVG 定义隔离及全局配置。
- 新增 Tabs 激活指示线的局部、全局可见性与位置配置。
- 修复回弹过程中消失轮廓反向长出，并改善动画时长内的运动分布。
