# 介绍

<card>

## 从 Vuesax 开始

Sax Design Vue 的起点，是对 **Vuesax 的一次复活尝试**。

Vuesax 的 Vue3 版本停止持续更新后，我仍然喜欢它的视觉风格：圆角、柔和阴影，以及有表现力的控件。因此，最初的想法很简单——让这套组件在 Vue3 中继续生长，并用 TypeScript 梳理它的 API。

</card>

<card>

## 有亿点点不一样

随着迁移和完善，我决定在这个基础上做些更大胆的尝试，让 Sax Design Vue 逐渐形成自己的方向。

保留 Vuesax 带来的视觉灵感，继续探索无边框表面、凹陷阴影、材质与动效；同时补上复杂数据应用需要的表格能力，以及聊天、推理、计划审批等常用 Agent 交互组件。

这就是“有亿点点不一样”的由来：从一套喜欢的组件出发，在实际开发中继续扩展它能做的事。

</card>

<card>

## 表格的灵感

Table 的功能与交互设计参考了 **vxe-table**。它在复杂业务表格上的积累，为编辑、校验、树形与分组、表格式交互等能力提供了很好的参考。

我结合 Sax Design Vue 的视觉语言和配置方式，逐步完善表格，并加入动态行高、行列双向虚拟化与按索引数据源，让复杂功能和大数据渲染能够一起使用。

感谢 Vuesax 带来的设计启发，也感谢 vxe-table 在业务表格上的探索。

</card>
